日不良率趋势（当前筛选）

不良率 = 不良数 / 投入数；用于判断异常是突发还是缓慢漂移。

规则：R1_3SIGMA = 连续 3 点 |z| ≥ 3；R2_SEVEN_POINT = 连续 7 点同侧且均值偏移 ≥ 2σ。基线冻结在前 60 天小时均值。

Agent 演进路线：L0 → L3

当前交付只做到 L2 的规则版建议，未接入真实 LLM，也不做自动执行；L3 是愿景，不是已实现能力。

护栏（为什么现在不放开自动执行）

  • 只读：Agent 不写 MES/EAP，不下发配方，不调机台参数。
  • 可解释：每条建议必须挂到一条告警 + 一个参数 + 一个回溯窗口。
  • 可回滚：建议以工单形式给到人，人确认后才执行。
  • 可评估：建议采纳率、复判命中率、误报率持续回写。
  • 数据合规：真实数据不出厂，模型与日志留在内网。
